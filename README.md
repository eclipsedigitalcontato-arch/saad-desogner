# Saad® — Designer & Videomaker

Portfólio autoral de design e produção audiovisual. Construído com HTML, CSS e JavaScript puros, sem dependências de build.

## Como visualizar

Abra `index.html` no navegador ou use uma extensão de servidor local. Também pode publicar como site estático pelo GitHub Pages, Netlify, Vercel ou Lovable (mediante importação).

## Estrutura

- `index.html` — conteúdo e seções (hero, trabalhos, serviços, sobre, contato).
- `style.css` — identidade visual, responsividade e animações.
- `script.js` — menu mobile, ano do rodapé e configuração dos contatos.

## Ajustes para fazer antes do lançamento

1. Defina seu e-mail e Instagram no objeto `CONTACT` de `script.js`. Os botões não apontam para terceiros enquanto estiverem vazios.
2. Substitua as quatro peças demonstrativas em `#trabalhos` por imagens/vídeos dos seus projetos reais. Atualmente são **conceitos demonstrativos**, não cases de clientes.
3. Edite os textos pessoais e de apresentação no HTML, conforme sua experiência.
4. Conecte seu domínio e publique pela plataforma de preferência.

## Direção de arte

Estética editorial, fundo off-white, preto carvão e verde-lima, tipografia Space Grotesk e DM Sans; arte desenvolvida no CSS para evitar fotos genéricas e aspecto de template pronto.

## Privacidade

Site estático, sem formulários ou analytics. Fontes são carregadas pelo Google Fonts, o que faz uma requisição externa.
